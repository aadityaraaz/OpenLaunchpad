# OpenLaunchpad 0.1.0 — Public Preview

A free, native macOS application launcher built with SwiftUI and AppKit. No subscriptions, activation, telemetry, or paid feature gates.

## Download and install

**Apple silicon · macOS 26 or later.** Intel builds are not included in this preview.

- **DMG:** open `OpenLaunchpad-0.1.0-macOS-arm64.dmg`, then drag OpenLaunchpad into Applications.
- **ZIP:** extract `OpenLaunchpad-0.1.0-macOS-arm64.zip`, then move OpenLaunchpad.app into Applications.
- **Checksums:** use `SHA256SUMS.txt` to verify either download with `shasum -a 256`.

This app is **ad-hoc signed, not Developer ID signed or notarized**. macOS may block its first launch. After attempting to open it, use System Settings → Privacy & Security → Open Anyway if you choose to run it.

## Changelog

This is the first public release:

- Fullscreen and movable window launchers with native materials, remembered position, and outside-click dismissal.
- Vertical scrolling or horizontal sliding pages, configurable grid and labels, keyboard/wheel/swipe navigation, and page dots.
- Ranked app and alias search with initials, accents, camel case, and pinyin matching.
- App-on-app folder creation, folder merging and renaming, manual reordering, cross-page movement, multi-selection, and batch organization.
- Name/date/color sorting, scoped layout reorganization, favorites, named profiles, and 30-step undo/redo.
- System/light/dark appearance, cached wallpaper blur and aerial stills, icon treatments, and Apps-style or Rocket logos.
- Custom application sources, background rescanning, hidden-app management, app information, Finder reveal, and Dock integration.
- Configurable global shortcut, optional F4, hot corners, login item support, display selection, and experimental opt-in trackpad pinch/spread activation.
- JSON backups, read-only legacy Launchpad import, atomic persistence, and conservative uninstall-to-Trash previews.
- Optional HTTPS update checks and native five-tab Settings.

Read the [full changelog](https://github.com/aadityaraaz/OpenLaunchpad/blob/v0.1.0/CHANGELOG.md) and [feature coverage](https://github.com/aadityaraaz/OpenLaunchpad/blob/v0.1.0/docs/FEATURES.md).

## Validation and known limitations

17 core checks and 24 integration checks pass. The optimized app's local ad-hoc signature and packaged downloads are verified before publication. This preview has no FPS guarantee or certified feature-for-feature equivalence claim.

Physical gestures, outside clicks, multiple displays, and full system icon appearance cycles still need broader hardware validation. Animated wallpaper playback, localization, and signed automatic updates are not included. See [validation notes](https://github.com/aadityaraaz/OpenLaunchpad/blob/v0.1.0/docs/VALIDATION.md).
